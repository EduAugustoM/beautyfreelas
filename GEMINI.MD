# Regras do Projeto

## Stack
- Next.js 15 com App Router
- TypeScript strict
- Tailwind CSS
- Supabase (auth + database)

## Padrões
- Componentes em /components com export default
- Server actions em /actions
- Sempre use 'use client' quando necessário
- Comentários em português

## Não faça
- Não instale bibliotecas sem perguntar
- Não mude o schema do banco sem confirmar
- Não use CSS modules, só Tailwind
